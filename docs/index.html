CrewKit
one tiny core. a crew of apps.

A lean, dependency-free automation skeleton — scheduler, config, state and notifications in ~430 lines of stdlib Python — proven by two distinct applications that share nothing but the core.

Get the skeleton on GitHub How Kiro built it

🦴 The skeleton

Five modules, one responsibility each. Copy core/ into any project and your app wakes up with a heartbeat, a memory and a voice.

config.pyJSON config + CREWKIT_* env overrides
clock.pyUTC time + a pure due-job scheduler
store.pyAtomic JSON state — crash-safe writes
notify.pyConsole, file & webhook sinks
runner.pyRuns due jobs, records outcomes, alerts on failure

🪄 Built with Kiro, spec-first

  • Steering files for product, tech and structure governed every session.
  • A spec (requirements R1–R6, design, tasks) was written before the code.
  • A custom agent (crewkit-builder) implemented the core and both apps via Kiro CLI, under a hard rule: finish only when the self-test passes.
  • A hook re-runs the deterministic self-test whenever a Python file changes.
  • Verified: 34/34 tests pass offline; both demo modes run in under a second.
